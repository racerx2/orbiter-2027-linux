The Windows Orbiter SDK headers the helper is built with: Orbitersdk/include of Orbiter 2024 (github.com/orbitersim/orbiter, tag 2024, 0cac7a31), MIT (LICENSE). A 2010 or 2016 module's view of the classes that changed since is in helper/compat2010.h. Not upstream: the Windows graphics client's own blocks of DrawAPI.h (compiled only into that client) and their notes are left out, OrbiterAPI.h's IMAGE_DDS note shortened, and gcGetCoreInterface (gcCoreAPI.h) returns NULL: the helper has no graphics client core, so the lookup always failed there.
