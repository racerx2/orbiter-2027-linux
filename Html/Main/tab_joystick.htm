Controllers

Joysticks, throttles, rudder pedals, button boxes and other game controllers work all at once, and can be plugged in and out while Orbiter runs. The Controllers page lists the controllers found, with the name each has in Config/Input/Devices.cfg and its buttons and axes.

No access

A controller the desktop doesn't give to the user (some button boxes, and pedals without buttons) is listed with the udev rule that does, for /etc/udev/rules.d/71-orbiter-controllers.rules.

Controllers work while Orbiter is in the background

If ticked, the controllers keep flying when another window has the focus, for example an external MFD or a map on another screen. The keyboard and the mouse stay with the Orbiter window.

Bindings

Every button, hat, axis, dial, keyboard key and mouse button can be bound to an Orbiter function, a key or key combination, an analog control (attitude, throttles, trims, toe brakes, view), an MFD button or a shift layer. The bindings are in Config/Input: Global.cfg for every vessel, and Vessels/<class>.cfg for one vessel class. Files changed while Orbiter runs are read again within a second; Read Config/Input again reads them at once. The file format is in the User Manual, section Advanced Configuration, Controllers and bindings.

The first time this version runs, Global.cfg is made from the old joystick settings, so a joystick works as it did before.
