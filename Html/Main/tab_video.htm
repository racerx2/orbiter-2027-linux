Video settings

On this page you select the graphics engine and set up the simulation window: full screen or in a window, the full screen mode and the window size.

On Linux the graphics engine is the VulkanClient plugin; without a graphics engine Orbiter runs in console mode. The options below are the VulkanClient's; its documentation (Doc/VulkanClient/VulkanClient.html) describes them in detail.

3-D device

Lists the Vulkan devices found on this computer: graphics cards, and software renderers such as llvmpipe. Pick your graphics card; a software renderer is very slow.

Advanced: opens the VulkanClient Advanced Setup dialog (anti-aliasing, texture filtering, shadows and more).

Full Screen

Select this option to run Orbiter full screen. The Full Screen Mode list offers "True Full Screen (no alt-tab)", "Full Screen Window" (a window without frame that covers the screen) and "Window with Taskbar" (the same, leaving the desktop's panels visible). On Linux the display mode is never changed, so full screen uses the screen's current resolution, and switching to other windows works in all three modes.

Disable vertical sync: This allows Orbiter to update a frame without waiting for a synchronisation signal from the monitor. This can improve frame rates, but may lead to visual artefacts (tearing). Note that some video drivers allow to override application vsync settings, in which case this option has no effect.

Multiple displays: In "Full Screen Window" mode the window covers all screens of the desktop; in "Window with Taskbar" mode it takes the width of the desktop's work area instead of the screen.

Window

Select this option to run Orbiter in a window. You can specify the size of the render window here. Selecting one of the fixed aspect ratio options (4:3 normal, 16:10 widescreen or 16:9 widescreen) automatically adjusts the window width or height to maintain the aspect ratio. Large window sizes may reduce simulation performance.

Force window size: Orbiter sets the render window to the size given here again after the desktop has placed it. With this option ticked, the anti-aliasing setting of the Advanced Setup dialog is not available.
