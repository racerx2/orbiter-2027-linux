How to use Help

This help window can be opened from the Orbiter Launchpad dialog by pressing the "Help" button, or during a simulation by pressing Alt F1, or selecting "Help" from the main menu (F4).

You can close the window by clicking the "X" button in the top right corner.

The help window's title bar belongs to the desktop, so what a double-click does there depends on the desktop. In-game dialog boxes drawn in the simulation window collapse when you double-click their title bar.

You can navigate the help system with the contents tree on the left side of the help window.

Some scenarios come with context-sensitive help pages, which can be accessed by pressing the "Scenario" button in the navigation bar, if it is shown.

If the spacecraft you are currently controlling provides a help file, it can be accessed by pressing the "Vessel" button in the navigation bar.
